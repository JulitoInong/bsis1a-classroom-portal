FIXES IN THIS VERSION
======================
1. Home now refreshes student data on pageshow, fixing stale profile photos when returning from Profile using Back.
2. Profile upload verifies that the students.avatar_url row was actually updated.
3. Profile and Home add a cache-busting query to avatar image URLs.
4. Google login now reports the actual OAuth error message when Supabase returns one.
5. Login portal gets a dedicated stylesheet so the Google login section does not inherit conflicting layout rules.

TEST ORDER
==========
- Hard refresh the login page (Ctrl+Shift+R).
- Sign in with Google.
- Complete registrar if needed.
- Open Profile.
- Upload a new image.
- Confirm "Profile photo updated and saved."
- Click Back to Home.
- The new image should appear immediately.
- If upload fails, the displayed error message now contains the returned Supabase error.

IMPORTANT
=========
If the upload error says the bucket/policy is missing, run storage-migration.sql in Supabase SQL Editor.
