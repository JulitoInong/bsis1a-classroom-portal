DEPLOYMENT
1. Upload the contents of this folder to the Netlify site. The uploaded root must contain index.html, manifest.webmanifest, sw.js, and the application folders.
2. Use the HTTPS Netlify URL for all live testing.
3. Do not use 127.0.0.1 or localhost as the public/PWA URL.
4. After deployment, hard-refresh the site or reinstall the PWA if an older service-worker cache is present.

GOOGLE ACCOUNT SWITCH TEST
1. Sign in with Google account A.
2. On Registrar, click "Use a different Google account".
3. The current Supabase browser session is signed out locally.
4. Only Supabase authentication storage is removed; unrelated browser storage is preserved.
5. Login remains on the login page instead of auto-redirecting to Registrar.
6. Google OAuth is started with prompt=select_account.
7. Choose Google account B.
8. The app returns to Registrar using account B.

ADMIN GOOGLE LOGIN
The code generates the callback as /admin/admin-callback.html from /admin/index.html. The exact production URL above must be allowed in Supabase.
