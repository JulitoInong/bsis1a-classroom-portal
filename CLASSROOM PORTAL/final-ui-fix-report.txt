BSIS 1-A FINAL UI / SCHEDULE FIX REPORT
========================================

Verified static changes in this build
-------------------------------------
1. Replaced the old opaque-black logo asset with the supplied transparent BSIS 1-A logo.
2. Removed the logo-container black fill on the shared brand/header treatments.
3. Student navigation hamburger is now part of the header flow instead of a floating fixed control.
4. Student header is sticky so navigation remains visually anchored while scrolling.
5. Student drawer/backdrop start below the sticky header.
6. Student body scrolling is locked while the drawer is open.
7. Admin navigation hamburger is now part of the admin header flow instead of a floating fixed control.
8. Admin drawer/backdrop start below the sticky header.
9. Admin header has one sign-out control; the duplicate sidebar sign-out control was removed.
10. Admin recognition continues to be controlled by public.admin_users through the existing shared recognition layer.
11. Schedule Portal now separates Regular Class and Online / Async views.
12. Admin Schedule management supports Regular, Online, and Asynchronous class modes.
13. Schedule data includes an idempotent default-data section.
14. Regular schedule defaults are based on the uploaded enrollment form.
15. Online schedule defaults are based on the timetable supplied in the project conversation.
16. Student schedule shows only published entries.
17. Admin schedule shows and manages all entries available to the recognized admin.
18. Responsive layouts were tightened for mobile, tablet, laptop, and wide screens.
19. Schedule navigation and modal/header controls have keyboard/escape handling.
20. Existing Supabase authentication and admin-recognition scripts were preserved.

Important source handling
-------------------------
- The uploaded enrollment form was used for the regular timetable's days, times, subjects, and rooms.
- Instructor names were taken from the user's supplied schedule text.
- The supplied online timetable did not assign different subjects to different online weekdays, so the build uses the listed online sequence on Monday, Wednesday, Thursday, and Friday as provided.
- Vacant 11:00–12:00 and 3:00–4:00 blocks were not inserted as classes.
