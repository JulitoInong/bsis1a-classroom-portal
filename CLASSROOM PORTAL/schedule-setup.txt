BSIS 1-A SCHEDULE SETUP
=======================

1. Open Supabase SQL Editor.
2. Run schedule-migration.sql once.
3. The migration creates/updates class_schedule, RLS policies, indexes, and the default BSIS 1-A schedule.
4. Open the Admin Portal -> Schedule to review entries.
5. Regular Class / F2F entries come from the uploaded enrollment form.
6. Online / Async entries use the online timetable supplied in the project conversation.
7. Admins can edit the class mode, day, time, subject, instructor, room, notes, and published state.

Class modes supported:
- regular
- online
- asynchronous

Student Portal:
- Schedule -> Regular Class
- Schedule -> Online / Async

Only published entries are visible to students.
