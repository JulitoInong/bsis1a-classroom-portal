BSIS 1-A ADMIN MANAGEMENT SETUP

1. Keep admin-auth-migration.sql already completed.
2. Run admin-management-migration.sql ONCE in Supabase SQL Editor.
3. Keep the same authorized admin account in public.admin_users.
4. Open admin/index.html through Live Server.
5. The Admin Dashboard now contains:
   - Student Records
   - Search + PFP filter + sorting
   - View / Edit student profile
   - Announcements management
   - Class Information management
   - Admin sign-out

Content tables created:
- public.announcements
- public.class_information

Students can read only published content.
Admins can create, edit, publish/unpublish, and delete content.

The student-facing Home page is intentionally not changed by this package yet;
the next integration can display published announcements and class information
there without changing the existing login/registrar/profile flow.
